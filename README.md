# SystemOverview

TontooOS About window: a 320x580 TontooUI card with its own close and
minimize traffic lights, laptop illustration, spec grid (Chip, Memory,
Kernel, TontooOS) and a More Info button. Memory shows the real installed
RAM snapped down to standard levels. Rendering is TontooUI on Vello/WGPU,
the theme follows the live system Dark/Light scheme through the settings
daemon, and `en_us`/`de_de` strings load from `lang/` via the
Accessibility framework.
