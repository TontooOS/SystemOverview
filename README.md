# SystemOverview

TontooOS About window: a 320x580 UIKit card with close/minimize controls,
laptop illustration, spec grid (Chip, Memory, Kernel, TontooOS) and a
More Info button. Memory shows the real installed RAM snapped down to
standard levels. Follows the live system Dark/Light scheme and loads
`en_us`/`de_de` strings from `lang/`.
